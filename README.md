# Site Vyon Lab

Landing page institucional da Vyon Lab, focada em geração de leads, apresentação de serviços e conversão para WhatsApp.

## Estrutura do projeto

- index.html → estrutura principal do site
- style.css → estilos visuais
- script.js → interações e funcionalidades
- /ativos → imagens, ícones e arquivos estáticos

## Publicação

Este repositório está conectado ao Vercel.

Fluxo de atualização do site:

1. Alterar arquivos locais ou exportados do Antigravity
2. Enviar para este repositório (upload ou commit)
3. O Vercel faz deploy automático
4. O domínio é atualizado em cerca de 1 minuto

## Alterações comuns

### Trocar número do WhatsApp
Editar diretamente no `index.html` o link do botão.

### Alterar textos do site
Modificar os conteúdos dentro do `index.html`.

### Atualizar estilos
Editar o arquivo `style.css`.

## Objetivo do site

Apresentar a Vyon Lab como assessoria de marketing, performance e IA,
gerando contatos qualificados e novos clientes recorrentes.
